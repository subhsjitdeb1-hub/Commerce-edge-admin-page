Commerce Edge Admin

Standalone HTML: open Commerce_Edge_Admin.html offline on laptop; on iPhone, use Safari where possible. IndexedDB data is device/browser-local. Export JSON backups regularly.

PWA package: host these files on an HTTPS static host (e.g. GitHub Pages) to install as a Home Screen app and benefit from service-worker caching. Simply opening index.html as a local file will not install the PWA.

Do not clear Safari/browser data unless you have a backup. This app is not cloud synced.
